Pick a screen above. EXT (320×240) is the main UI and stays unchanged. INT (240×135) is the complementary menu, styled as the inside of a Gibson (CYD scheme: teal-black board, traces, IC plate, edge-connector): BOTcorps bar + clock, sub-options, selection and key-cap hints — never repeating titles or status already on EXT. Bot rain ambience sits behind INT on rain/intro/gibson/wifi/bluetooth/bot screens (not Terminal or Control). Keys: arrows, ENTER, ESC. Screensavers (Control panel → SCREEN SAVER row: ←→ picks BOTS / GIBSON / FLYBY / BOUNCE, ENTER tests it; SAVER ON/OFF and IDLE TIME drive a real idle timer) take over EXT only; INT stays a menu (look name + wake). Saver bots reuse BOT SHAPE, RAIN MODE and RAIN COLOUR. Saver choice is saved in localStorage botcorps.adv.saver.v1.
Where the rain colour / bot shape shows: EXT rain behind the screen on Rain boot, Intro, Gibson, Gibson role, Terminal, WiFi (+ radar, list), Bluetooth (+ radar, list), Bot (+ radar) and Control panel (live preview window under the rows); INT rain behind the chrome on Rain boot, Intro, Gibson, Gibson role, WiFi, Bluetooth and Bot screens (+ their radar / list); Screensavers BOTS, GIBSON, FLYBY and BOUNCE (every saver bot). Terminal EXT now has the rain behind its dimmed ESP32-board tiles (bot chips keep their own colours) and a typable prompt (scan, hunt, help, bots, rain <colour>, filter, ping, info, track, sniff, go <screen>, clear; Tab completes; TAB on an empty prompt opens the command menu dropdown; rain / shape change the real settings). Selected-bot screens: the bot follows the pointer, tap / ENTER (INT “pet”) = happy, double tap = spin, sleeps after ~20 s and wakes on touch. The Gibson role card is drawn as an ESP32 dev board. Not coloured: Control panel INT (static board) and the ivory GIBSONbot (fixed colour). MIXED keeps the original multi-colour rain; picking a colour switches RAIN MODE to SOLID.
