# MORPHEUSbot boot entrance ideas A/B/C. MOCK ONLY.
Built on the renamed boot frames (name and pince-nez). Sequence: 14 frames where the MORPHEUS chip spot powers on (dark, flicker, lit) -> original f0-49 (login/password) -> 60-frame choice -> original f50-84 (ACCESS GRANTED, wipe to GIBSON).
- A (tap, flanking): the RED chip bot sits left of MORPHEUS and the BLUE one right of him, on the board doodle columns. The user taps red (ENTER); red brightens with a halo and blue dims. Both stay until the wipe at f74.
- B (tap, U2 plate): the U2 TERMINAL plate under MORPHEUS turns into a slot holding RED|BLUE side by side on a trace bus. The user taps red; red brightens and blue dims; the plate returns to ACCESS GRANTED.
- C (auto, most faithful): the same plate slot, but there is no tap. MORPHEUS sends a pulse down his trace and along the bus into RED, red brightens, blue dims, and the boot continues by itself.
- Chip bots: CYD style (square body, gold pins, header meander, 3-tone metallic window, black face with white outline, two eyes) and a GLCD label: red "ENTER", blue "TBD".
- Blue's action is a placeholder that has not been designed.
- Touch targets at 1x: plate chips 48x30 (with pins), flank chips 35x39.
