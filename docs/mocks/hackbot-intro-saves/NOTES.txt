Baseline gate: the same scripts on the v1.2.16 sim from cd5e118.

What this mock adds (the rest of HACKbot is unchanged):
- Opening HACKbot from HOME / pager now lands on a SAVE SLOTS intro. The
  intro itself is the 3-slot picker (Mobandy). U/D moves between slots,
  A opens the selected slot, B goes back home. The locked level typist
  (INTRO) still appears after NEXT LEVEL, RETRY, or a NEW GAME slot, and
  via the sim "dllevel" shortcut.
- Each slot stores full progress: level, score, towers hacked, files
  downloaded. Empty slots show NEW GAME.
- Saves go to the CYD SD card: /BOTcorps/hackbot/slot1.sav .. slot3.sav
  (16-byte little-endian record, magic "HB1\0", ver 1). If the card is
  missing or the write fails, the same 16 bytes go in NVS namespace
  "botcorps", keys hbsl1..hbsl3. The slot picker labels this:
  "EX.DATA  SD /BOTcorps/hackbot/" and the save-confirm card shows the
  exact file (slot1.sav) plus "NVS FALLBACK IF NO SD".
- The host sim never mounts SD or NVS. It shows canned EXAMPLE DATA
  (slot 1 filled: L3, score 860, towers 3/5, files 2/3; slots 2 and 3
  NEW GAME), stamped EX.DATA so the numbers are not live saves.
- During play, B on the field (no tower open) opens a PAUSE menu with
  RESUME, SAVE, and EXIT (U/D, A selects, B resumes). SAVE writes the
  slot in use and shows SLOT SAVED. EXIT returns home without saving.
  B on an open tower still closes it (locked).
- The 90s trace timer is frozen while paused. Rain and the camera keep
  moving.
- The card is the locked LEVEL CLEAR / TRACED frame (12,60 216x181,
  magenta double border, 2x title). The real HACKbot d-pad deck stays
  at y=247. Rain, chrome, fonts, and colours are the locked play look.
